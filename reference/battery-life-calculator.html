计算过程
1. 有效可用容量
C有效 = C标称 × DOD = -- mAh
2. 工作电流计算
I工作 = P工作 / V电池 × 1000 = -- mA
3. 每日工作耗电
t工作日 = 次数 × 时长 / 60 = -- h
C工作日 = I工作 × t工作日 = -- mAh
4. 每日待机耗电
C待机日 = I待机 × 24h = -- mAh
5. 每日总耗电
C总日 = C工作日 + C待机日 = -- mAh
6. 续航计算
纯待机 = C有效 / I待机 / 24 = -- 天
综合 = C有效 / C总日 = -- 天
7. 充电参数互算
I充 = C标称 × 倍率 = -- mA
8. 充电时间
理论 = C标称 / I充 = -- h
实际 = 理论 / 效率 = -- h
工程说明：
• 锂电池充电为CC/CV模式，恒流阶段约充入80%容量，恒压阶段占20%时间，实际总时间约为理论值的1.2~1.5倍
• 本计算未考虑电池自放电（每月约3~5%），长期放置需额外预留
• 待机电流含PIR感应+MCU+电源管理IC静态功耗
选型建议：
• 循环寿命优先：DOD取50%，容量翻倍换寿命
• 空间优先：DOD取80%，注意低温放电容量衰减
• 充电倍率≤0.5C为常规，0.1~0.2C为慢充长寿命方案
